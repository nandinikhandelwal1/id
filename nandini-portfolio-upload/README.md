# Nandini Khandelwal Interior Design Portfolio

## Deploy to Netlify
Drag this entire folder or ZIP into Netlify Drop. The homepage is `index.html`; no build command is required.

## Editing
Open `/admin/` on the deployed website. This lightweight editor stores a preview in the current browser. Download the website data for backup. For permanent public edits, update `content/site.json` and `content/project.json`, replace placeholder files in `assets/`, then redeploy.

## Featured project
The portfolio intentionally includes one project only: **Celebrity Residence — 3 BHK Residential Home**. It keeps the client identity and exact location private. Replace the six SVG placeholders with project visuals using the same filenames.
