# Nandini Khandelwal Interior Design Portfolio

## Deployment
The site is a static portfolio with `index.html` as its homepage. It is published through GitHub Pages from the repository's `main` branch and can also be deployed to Netlify without a build command.

## Editing
Open `/admin/` on the deployed website. This lightweight editor stores a preview in the current browser. Download the website data for backup. For permanent public edits, update `content/site.json` and `content/project.json`, replace placeholder files in `assets/`, then redeploy.

## Featured projects
The portfolio presents two case studies: **2 BHK Residential Home**, with its moodboard, technical PDFs and inline 3D model; and **Sculpted Savannah**, with its final chair photograph, A1 presentation board and project book.
